Backend Model Architecture: Deteksi Timpa Teks (PKM)

Visual perbandingan pendekatan model AI/ML pre-trained ringan & fine-tuning

1. YOLOv8n / YOLOv11n (Nano)

Sangat Ringan (~6MB - 14MB)

Object Detection untuk mendeteksi bounding box area teks yang tertimpa / di-oret. Menggunakan transfer learning/fine-tuning pada dataset dokumen.

Kelebihan

  • Inference sangat cepat (realtime/CPU friendly)
  • Cocok untuk deployment lokal/edge (FastAPI + ONNX/TensorFlow Lite)
  • Mudah di-fine tune dengan sedikit data (roboflow/labeling)

Catatan

  • Hanya mendeteksi *posisi/lokasi* timpa teks, belum membaca isi teks asal di bawahnya

2. OpenCV + EasyOCR / PaddleOCR (Hybrid Pipeline)

Ringan-Sedang (~50MB - 150MB)

Kombinasi Image Processing (OpenCV Morphological / Contour Filtering / Thresholding) + Pretrained OCR untuk memisahkan layer tinta/teks bertumpuk.

Kelebihan

  • Dapat memisahkan piksel warna/kontras tinta yang bertumpuk
  • Tidak perlu melatih neural network berat dari nol
  • Menggunakan pretrained EasyOCR/PaddleOCR siap pakai

Catatan

  • Sensitif terhadap perbedaan warna tinta/pencahayaan gambar

3. TrOCR / Donut Fine-Tuning (Transformer-based)

Sedang (~200MB - 400MB)

Model Document AI berbasis Vision Transformer (Microsoft TrOCR / Naver Donut) versi small/nano untuk membaca teks yang mengalami noise/overwriting.

Kelebihan

  • Sangat akurat membaca teks meskipun terdistorsi/tertutup
  • Model SOTA (State-of-the-art) untuk PKM nilai plus akademik tinggi

Catatan

  • Membutuhkan RAM/VRAM lebih besar dibanding YOLO
