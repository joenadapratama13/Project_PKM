Design Section 1: System Architecture & Data Flow

Arsitektur Backend Vision Transformer ONNX (FastAPI + TrOCR-Small CPU)

Backend Data Flow Pipeline
[CLIENT / FRONTEND]
POST /api/v1/detect-text (multipart/form-data with image file)
⬇
[FASTAPI ENDPOINT ROUTER]
File validation (PNG/JPG/WEBP), Image Loading (PIL/OpenCV), Resize & Normalization
⬇
[REGION PROPOSAL & TEXT CROPPER]
Detect text lines/bounding boxes via OpenCV Contours / MSER / Craft-Light
⬇
[ONNX RUNTIME INFERENCE ENGINE]
TrOCR Encoder-Decoder ONNX model (Int8/FP32 CPU provider) -> Autoregressive Token Generation
⬇
[RESPONSE SYNTHESIS & POST-PROCESSING]
JSON Payload Output: Extracted text, Confidence score, Bounding boxes, Overwritten flag
