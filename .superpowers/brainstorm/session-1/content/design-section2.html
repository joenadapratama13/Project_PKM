Design Section 2: Component Breakdown & Model Handling

Struktur Modul Backend & Manajemen Model ONNX TrOCR

1. Preprocessor Module (core/preprocessor.py)

  • Image Normalization: Resizing citra masukan ke format $384 \times 384$ px & normalisasi RGB Mean/Std.
  • Noise Reduction & Bounding Box Extractor: Menggunakan Morphological Thresholding OpenCV untuk memisahkan baris teks/kata menjadi potongan region of interest (ROI).

2. ONNX Model Handler (core/onnx_engine.py)

  • ONNX Session Management: Memuat berkas encoder_model.onnx dan decoder_model.onnx sekali saja saat server FastAPI dinyalakan (Singleton pattern).
  • Decoder Loop: Menjalankan autoregresif decoding (token-by-token) menggunakan greedy search / beam search untuk menghasilkan kata asli.

3. Post-Processor & Evaluator (core/postprocessor.py)

  • Tokenizer Decoding: Mengubah token ID menjadi string teks terbaca (menggunakan HuggingFace TrOCR Fast Tokenizer).
  • Overwriting Confidence Score: Menghitung nilai keyakinan bahwa teks tersebut mengalami timpaan vs teks normal.
