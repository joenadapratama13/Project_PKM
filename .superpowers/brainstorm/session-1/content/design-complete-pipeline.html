Alur Lengkap Backend: 3 Stage Pipeline Cerdas

Deteksi Keaslian Dokumen -> Cari Sumber Internet -> Rekonstruksi AI Visual

Logic Flow Backend
STAGE 0: Gatekeeper / Deteksi Keaslian Dokumen

Sistem mengecek: "Apakah ada coretan / timpaan teks di gambar ini?"

TIDAK ADA CORETAN (ASLI):

🛑 STOP LANGSUNG. Output: Status: Dokumen Asli / Bersih.

ADA CORETAN / TIMPAAN:

➡️ Lanjut ke STAGE 1 (Pencarian Sumber).

⬇
STAGE 1: Internet / Knowledge Base Matching

Mencari sumber dokumen pembanding di internet menggunakan kata kunci dari teks yang bersih.

✔ Jika Ketemu: Ambil kata asli dari sumber (Akurasi 100%).

⬇
STAGE 2: Vision Transformer AI Fallback (TrOCR)

JIKA TIDAK KETEMU DI INTERNET: Otak AI TrOCR menganalisis visual sisa garis tinta untuk menebak tulisan asli.
