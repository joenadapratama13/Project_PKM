Convert RGB to HSV / LAB Color Space + Adaptive Thresholding (OpenCV)

STEP 2: Ink Layer Separation (Pemisahan Tinta)

Teknik: K-Means Color Clustering / Morphological Dilation Filter / Difference of Gaussians (DoG) untuk memisahkan coretan penimpa vs teks latar belakang.

⬇
STEP 3: Text Restoration & OCR Inference

Model OCR Pretrained (EasyOCR / PaddleOCR / Manga-OCR) membaca karakter dari gambar layer yang sudah dibersihkan.

Rekomendasi Model Pre-trained untuk OCR & Separasi:

A

OpenCV + PaddleOCR (Recommended)

Model OCR sangat ringan (~15MB MobileNet backbone), sangat presisi untuk teks dokumen/cetak. Sangat cepat di CPU.

B

OpenCV + EasyOCR (PyTorch-based)

Mudah diintegrasikan dengan Python, mendukung 80+ bahasa, tetapi sedikit lebih berat RAM ketimbang PaddleOCR.

C

OpenCV + TrOCR-small (HuggingFace Transformers)

Akurat untuk tulisan tangan (handwritten) yang tertimpa, menggunakan Vision Transformer pre-trained siap pakai.
