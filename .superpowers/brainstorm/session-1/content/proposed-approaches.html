Proproposal 3 Pendekatan Backend (FastAPI + CPU Friendly)

Membandingkan kelebihan, kekurangan, dan rekomendasi model untuk PKM Anda

⭐ REKOMENDASI UTAMA

1. Hybrid OpenCV Pre-Filtering + Pre-trained PaddleOCR

Ukuran: ~15-30MB | RAM: < 300MB | Cepat di CPU (50-200ms)

Kombinasi algoritma pemisahan stroke (Difference of Gaussians & Thinning) OpenCV + PaddleOCR (PP-OCRv4 Mobile model). Mendeteksi & membaca teks cetak maupun tulisan tangan di CPU laptop biasa.

Kelebihan

  • Model sangat ringan dan cepat di CPU tanpa GPU
  • Akurasi membaca tulisan cetak & tangan sangat bagus
  • Mudah dideploy di FastAPI & siap demo PKM

Catatan

  • Membutuhkan tuning threshold filter OpenCV untuk oretan hitam pekat

2. Vision Transformer ONNX (TrOCR-Small ONNX CPU)

Ukuran: ~250MB | RAM: ~600MB | Speed: 0.8-1.5 detik/kata

Menggunakan model HuggingFace microsoft/trocr-small yang dikonversi ke format ONNX Runtime CPU. Membaca teks bertumpuk secara End-to-End dengan kecerdasan konteks Transformer.

Kelebihan

  • Akurasi SOTA (State-of-the-Art) untuk huruf terpotong/tertimpa
  • Nilai komputasi & bobot akademik sangat tinggi di PKM

Catatan

  • Ukuran file model lebih besar (~250MB)

3. OpenCV Line Inpainting + EasyOCR Pipeline

Ukuran: ~90MB | RAM: ~400MB | Speed: 200-500ms

Deteksi garis oretan (Hough Line Transform) -> Hapus & Rekonstruksi piksel tertutup (CV2 Inpainting Telea/NS) -> OCR membaca tulisan yang sudah dibersihkan.

Kelebihan

  • Bisa menampilkan visual "Sebelum vs Sesudah Ditinggalkan Oretan" di UI Frontend

Catatan

  • Huruf yang tertimpa parah bisa menjadi agak kabur saat di-inpaint
