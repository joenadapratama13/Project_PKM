Analisis Khusus: Pemisahan Tinta Warna Sama (Hitam ditimpa Hitam)

Kombinasi Teks Cetak & Tulisan Tangan (C + Y)

Tantangan Utama:

Nilai warna piksel (RGB/HSV) antara teks asli dan penimpa adalah SAMA (Hitam). Thresholding warna biasa TIDAK BISA memisahkan layer tinta ini.

3 Pendekatan Model Backend Tanpa Train Dari Nol (Pre-trained):

Approach 1: Deep Vision Transformer OCR (TrOCR-small + Custom Fine-Tune)

REKOMENDASI UTAMA DARI MODEL AI

Menggunakan pre-trained microsoft/trocr-small-handwritten atau trocr-base-stage1. Vision Transformer (ViT) secara intuitif dapat mengenali pola karakter meskipun terpotong/tertimpa garis oretan hitam.

Kelebihan

  • Model SOTA HuggingFace siap pakai
  • Sangat kuat untuk teks cetak MAUPUN tulisan tangan
  • Hanya perlu fine-tune beberapa epoch dengan dataset synthetic text overlay

Catatan

  • Butuh PyTorch / Transformers di backend

Approach 2: OpenCV Morphological Stroke Filtering + PaddleOCR

HYBRID IMAGE PROCESSING + LIGHTWEIGHT OCR

Memanfaatkan perbedaan ketebalan stroke & kontur (Difference of Gaussians / Thinning algorithm) untuk menghilangkan garis oretan lurus/silang sebelum dilempar ke PaddleOCR.

Kelebihan

  • Sangat ringan di CPU (tanpa GPU)
  • Inference hitungan milidetik

Catatan

  • Membutuhkan tuning threshold heuristik OpenCV

Approach 3: Autoencoder Inpainting (Lama / OpenCV Inpainting) + OCR

DEEP INPAINTING RESTORATION

Mendeteksi garis penimpa dengan model U-Net ringan, merestorasi/menghapus bagian garis (Inpainting), lalu membaca huruf dengan OCR.

Kelebihan

  • Hasil gambar pemisahan teks sangat bersih visualnya
